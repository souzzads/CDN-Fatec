# Estrutura de Dados II · Revisão completa

Site estático de revisão de Algoritmos e Estrutura de Dados II (Complexidade, Busca Sequencial, Busca Binária, Pilhas e Listas Encadeadas), com exemplos em Python e exercícios com resposta.

## Arquivos
- `index.html`: conteúdo
- `style.css`: visual e tema claro/escuro
- `script.js`: simulador de busca binária e botão de tema

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie estes arquivos para a raiz.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Aguarde um minuto: o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
